# mProfile visual covers

This Minecraft 26.3 resource pack supplies five original bitmap-font banners for mProfile's native dialogs.

| Cover | Glyph |
|---|---|
| Forest | `U+E101` |
| Nether | `U+E102` |
| Ocean | `U+E103` |
| End | `U+E104` |
| Space | `U+E105` |

The font key is `mprofile:covers`. Keep the ZIP unchanged when using mProfile's automatic SHA-1 verification. The artwork and pack files are distributed under the repository's MIT License.
